# Landing Page Project

This is a student project built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course. The goal of this project is to recreate a landing page from a provided design image using HTML and CSS, with a focus on practicing layout techniques such as Flexbox and consistent styling.

## Features

- Clean HTML and CSS structure
- Flexbox layout
- Custom fonts and color scheme based on provided design
- Four main content sections + footer
- Responsive structure (not mobile-optimized yet)
- Personalized content and royalty-free images

---

This project is a part of The Odin Project curriculum and is intended for learning purposes only.
